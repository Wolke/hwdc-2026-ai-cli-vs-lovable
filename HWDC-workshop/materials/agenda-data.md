# HWDC 真實議程附件

附件 `hwdc-agenda-2026.json` 來自 [HWDC 2026 官方議程](https://hwdc.ithome.com.tw/2026/agenda)，2026-10-13 擷取。兩天共 70 筆（各 35 筆）；12 筆休息時段不列為可收藏議程，原始資料另存於 evidence/agenda-raw.json。

- `id`：官方議程 ID，不因排序或重複題目而變動。
- `title`、`speaker`、`speakers`：官方標題與講者；講者未列時不要猜。
- `tags`：完整主題標籤；同一場可有多個主題，任何一個相符都應被篩出。
- `track`：相容舊程式的第一個標籤，正式篩選請使用 tags。
- `room`、`startsAt`、`endsAt`：會議室及含日期、+08:00 的時間。
- `sourceUrl`：該筆議程官方頁面。

官網時間以臺北活動的本地時間解讀，加上 +08:00，不改變場次時段。林建宏這場的官方登錄為 13:00–15:00，包含前 30 分鐘環境準備。原始資料、查詢及轉換方式見 evidence/agenda-source.json。

## 如何提供給 Agent

Lovable：上傳 JSON 作為附件，再貼初版短提示。Codex：同一份資料已置於 starter/src/sessions.json，直接指定該檔案。不要把整份 JSON 貼進 prompt。

開課使用這份固定快照，兩套工具共用；不在建置時要求 Agent 各自重新抓網頁。若課前需要更新，應重新擷取、重新核對並讓所有人使用同一版。

# 第二版需求：收藏衝堂提示

在第一版上加入收藏議程衝堂提示，保留所有既有功能和收藏資料。

1. 比較全部收藏議程，不受搜尋、主題篩選或目前視圖影響。
2. 以時間區間判斷。部分重疊、完全包含及相同時段都算衝堂，首尾相接不算。
3. 規則為 a.start < b.end && b.start < a.end，時間要先轉換成可比較的時間值。
4. 清楚顯示衝堂的兩個議程名稱及各自時段。同一對只列一次，不與自己比較。
5. 不自動取消任何收藏，讓使用者自己決定。
6. 取消收藏後即時更新提示。
7. 維持原 localStorage 鍵名與 ID 格式，重新整理仍保留第一版的收藏。

## 驗收（B1–B6，共 6 項）
| ID | 收藏組合或操作 | 預期結果 | 結果 |
|---|---|---|---|
| B1 | S01 + S02 | 部分重疊，提示 1 對 | 未測 |
| B2 | S01 + S04 | 完全包含，提示 1 對 | 未測 |
| B3 | S05 + S06 | 相同時段，提示 1 對 | 未測 |
| B4 | S01 + S03 | 09:40 首尾相接，不衝堂 | 未測 |
| B5 | S01 + S02，搜尋 S01 的講者或切主題，再取消 S02 | 篩選時仍提示原衝突，取消後提示消失 | 未測 |
| B6 | 跨版本保留收藏並重做 A1–A6 | 第一版收藏仍在，既有功能全部通過 | 未測 |

每個案例先清除其他收藏。修改最多 5 分鐘，包含驗收。來不及的項目記錄未測，不猜測通過。

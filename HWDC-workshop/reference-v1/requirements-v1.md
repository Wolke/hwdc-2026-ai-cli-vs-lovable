# 第一版：我的 HWDC 議程

目標：讓參加者用真實 HWDC 2026 議程安排兩天行程。

資料：hwdc-agenda-2026.json，共 70 筆；本機 src/sessions.json 是同一份。固定使用附件，保留原始標題、ID、日期時間與來源。多位講者與多個主題不可遺漏。講者未列時顯示未提供即可。

## 共同比較的 UX 邏輯

1. 能看全部議程，顯示標題、講者、主題、會議室、日期與起訖時間；依日期時間排序。
2. 可搜尋名稱或講者；忽略頭尾空白和英文大小寫。
3. 日期、主題、搜尋可以一起使用（AND）。主題符合 tags 任一項就應列入；可清除條件。
4. 可加入或取消收藏，沒有重複；可只看自己的議程，知道收藏數量。
5. 搜尋無結果／尚無收藏時清楚說明，能接續操作。
6. 同一瀏覽器、同一網址重新整理仍保留收藏；桌面與 390px 手機均可完成核心操作。
7. 顯示公開資料來源與快照日期，不宣稱為官方網站。

## UI 自訂，兩個工具版本一致

色彩、字型、卡片或清單、導覽位置與視覺風格由學員決定。Lovable 與通用 AI 的兩個版本須採用相同 UI 設計。先用一句話描述自己的設計想法，再把相同要求交給兩套工具。不同學員可選不同風格，無須套用參考版的配色或布局。

不做登入、後端或額外爬取。儲存方式由 Agent 決定；參考解答以 localStorage 儲存 ID。第二輪必須保留第一版的格式與收藏。初版不必做衝堂或行事曆匯出。

短提示是起點；A1–A6 是人驗收時的清單。若有缺漏，再以實際操作描述補充，而非要求學員先寫完整工程規格。
